# 01 · PRD — 기능 명세와 MVP 범위

용어: **세션**=대화 하나. **루트 세션**=parentId가 null인 세션. **서브세션(가지)**=부모 메시지의 텍스트 일부(앵커)에서 파생된 세션.
**앵커**=가지가 시작된 부모 assistant 메시지 속 원문 범위. **요약 카드**=서브세션 요약을 부모 앵커 옆에 붙인 접이식 카드.

## F1. 채팅
- 세션 목록(루트 세션 + 트리 펼침), 새 세션 생성, 세션 삭제(하위 가지 포함 확인)
- 스트리밍 응답(토큰 단위 표시, 중지 버튼), 재시도
- 마크다운(GFM 표/체크리스트/취소선), 코드 블록 구문 강조 + 복사 버튼
- 수용 기준: 응답이 토큰 단위로 갱신되고, 중지 시 지금까지의 내용이 보존된다.

## F2. 가지 생성
- assistant 메시지에서 텍스트 선택 → 플로팅 액션 `[이게 뭐야?] [더 자세히] [직접 질문]`
  - 이게 뭐야? → 자동 첫 질문: `"{선택}"이(가) 뭐야?`
  - 더 자세히 → 자동 첫 질문: `"{선택}"에 대해 더 자세히 설명해줘.`
  - 직접 질문 → 입력창이 열리고 사용자가 질문을 작성
- 서브세션 생성 + 첫 질문 자동 전송(스트리밍 시작)
- 원문에는 **하이라이트 앵커**가 남고, 클릭하면 서브세션을 연다(현재 보기 모드 규칙에 따름)
- 앵커 저장: **메시지 원문(markdown source) 문자열 기준** `startOffset/endOffset` + `text`
- 앵커 복원: 렌더 시 **텍스트 매칭**으로 위치를 찾고, 여러 후보가 있으면 offset에 가장 가까운 것 선택
- 한 메시지에 앵커 여러 개, 같은 텍스트에 가지 여러 개(앵커 배지에 개수 표시) 허용
- 모바일: 길게 눌러 선택 → 화면 하단 액션바
- 수용 기준: 굵게/코드/링크가 섞인 범위를 선택해도 원문 offset이 정확히 저장되고, 새로고침 후 동일 위치에 복원된다.
- 여러 블록(문단·목록 항목 등)에 걸친 가지는 본문 배경 대신 메시지 왼쪽 여백의 **세로 영역 막대**로 표시한다(hover = 범위 강조, 클릭 = 가지 열기, ADR-030).

## F2-1. 서식·메모 (IMP-07, ADR-029)
- 같은 선택 메뉴에서 **형광펜·밑줄·글자색**(6색), **글꼴**(명조·고정폭), **굵게·기울임**, **서식 지우기**, **메모**.
- 서식·메모는 원문 offset 기준 별도 엔티티로 저장하며 답변 원문은 바꾸지 않는다(맥락에 영향 없음). 같은 범위의 같은 색을 다시 누르면 해제.
- 메모가 있는 텍스트는 점선 밑줄 + 아이콘, 클릭하면 팝오버에서 보기·수정·삭제. 백업·원격 동기화에 포함.

## F3. 맥락 상속
서브세션의 LLM 요청 `system`에 다음을 포함한다.
1. **조상 앵커 체인**: 루트 제목 → 각 단계 앵커 텍스트(+ 앵커가 속한 문장 발췌)
2. **부모 최근 대화**: 부모 세션에서 앵커 메시지까지의 최근 N개 메시지(기본 N=6, 설정 가능)
3. **지시문**: "학습자가 이 맥락에서 막힌 부분이다. 맥락에 맞춰 짧고 명확하게, 비유와 예시를 들어 설명하라"
- 맥락 구성은 순수 함수(`buildBranchContext`)로 core에 두고 단위 테스트한다.
- 서브세션 화면에서 "상속된 맥락 보기"로 실제 system 프롬프트를 확인할 수 있다.

## F4. 요약 되돌리기
- 서브세션 헤더 `[부모에 요약 붙이기]` → LLM이 1~2문장 요약 생성 → 확인/편집 후 저장
- 부모 메시지의 해당 앵커 옆(메시지 하단 카드 영역)에 **접히는 카드**로 표시. 카드 클릭 → 서브세션 열기
- 요약 재생성/삭제 가능. 마인드맵 노드에 요약 배지 표시

## F5. 보기 모드
| 모드 | 데스크톱 | 모바일(<768px) |
|---|---|---|
| 단일 | 한 세션 | 한 세션 |
| 분할 | 최대 3패널, 드래그로 크기 조절 | 상단 탭 전환 |
| 팝업 | 드래그/리사이즈 가능한 플로팅 창, 여러 개 | 바텀시트(스냅: 절반/전체) |
| 마인드맵 | dagre 자동 배치, 노드=제목+앵커+요약 배지. 클릭=열기, Shift+클릭=분할에 추가 | 전체화면 오버레이 |
- 앵커 클릭 시 기본 동작: 데스크톱=팝업, 모바일=바텀시트 (설정에서 "분할로 열기" 선택 가능)

## F6. 서브세션 헤더
- breadcrumb: `루트 > … > 현재` (중간 생략, 각 항목 클릭으로 이동)
- 원문 앵커 인용 블록: 부모 메시지 속 앵커 텍스트(앞뒤 문맥 일부 포함), 클릭 시 부모로 이동 + 앵커 플래시

## F7. 편의 기능
- 세션 제목 자동 생성(첫 응답 후 LLM으로 5~20자 제목; 가지는 앵커 텍스트로 초기 제목)
- Cmd/Ctrl+K 세션 검색(제목·앵커·메시지 본문 대상, 트리 경로 표시)
- 다크/라이트/시스템 테마

## F8. 설정
- 연결 카드: Claude CLI / Codex CLI / Anthropic API / OpenAI API / 원격 Bridge
  - 각 카드: 상태(미설치·미로그인·연결됨·오프라인·키 없음), 안내, 테스트 버튼
- CLI 설치·로그인 상태 감지(bridge 경유), 미설치/미로그인 안내 문구
- 원격 Bridge 페어링: QR 표시(데스크톱) / QR 스캔·코드 입력(모바일)
- **웹·모바일 원격 전용 (ADR-026)**: 웹·모바일은 PC 데스크톱 앱에 페어링해 PC의 학습을 보고(실시간 스트리밍 포함), 질문·가지·요약·이름 변경·삭제는 신호로 보내 PC가 CLI로 실행한다. 웹·모바일의 설정은 연결된 PC + 화면(테마·가지 열기 위치)뿐이며 API 키·로컬 저장·백업·모델 선택은 없다.
- 기본 provider, 세션별 provider 선택(세션 헤더), 대체(fallback) provider 순서
- 맥락 상속 N 값, 앵커 클릭 동작, 테마

## F8-1. 백그라운드 호스트 (IMP-07, ADR-028)
- 데스크톱에서 원격 페어링이 켜져 있으면 창을 닫아도 앱이 트레이(메뉴 막대)에 남아 페어링된 기기가 계속 보고 질문할 수 있다.
- 트레이 메뉴: [rhymebook 열기] · 원격 연결 상태 · [완전 종료]. 원격 페어링이 꺼져 있으면 기존처럼 창 닫기 = 종료(macOS는 앱 유지).

## F9. 백업 (2단계 피드백으로 추가)
- 전체 데이터(세션 트리·메시지·앵커·요약·보기 상태)를 버전이 있는 JSON 스냅샷 하나로 저장. **실시간 동기화가 아닌 시점별 사본**.
- 백업 위치: 파일(내보내기/가져오기, 항상 사용 가능) · 구글 드라이브(`drive.appdata` 앱 전용 숨김 폴더) · GitHub 저장소(fine-grained PAT, 단일 저장소, `backup.json` + 읽기용 마크다운).
- 지금 백업 / 자동 백업(끄기·변경 시·매일) / 최근 N개 보관.
- 복원: 합치기(id 기준, 더 최근 `updatedAt` 우선) 또는 전체 교체. 복원 전 현재 상태 자동 백업.
- 선택형 암호(패스프레이즈) 잠금: 기기에서 암호화 후 업로드.
- 비밀 값(API 키, 페어링 키, Drive/GitHub 토큰)은 백업에 포함하지 않는다. 토큰 보관 규칙은 API 키와 동일.

## 반응형 규칙(요약)
- 모바일 폭에서는 분할 → 탭 전환, 팝업 → 바텀시트, 마인드맵 → 전체화면
- 상세는 04-UX-SPEC.md

## MVP 범위
F1~F9 전부 + 플랫폼: 웹, 데스크톱(Electron), 모바일(Capacitor) 빌드 구성.
데이터는 로컬(IndexedDB) 저장.

## 범위 밖 (Out of Scope)
- 퀴즈/플래시카드, 간격 반복(SRS)
- 계정, 실시간 클라우드 동기화, 멀티 디바이스 데이터 동기화 (백업/복원은 F9로 범위 안)
- 파일/이미지 업로드, 웹 검색, 도구 호출(에이전트 기능)
- 협업/공유 링크
- 앱스토어 실제 출시(빌드 구성까지만)
