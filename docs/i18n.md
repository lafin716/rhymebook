# 번역 참여 안내 (Translations)

octobooks의 모든 화면 문구는 언어별 JSON 파일에 있습니다. 코드를 몰라도 JSON만 고쳐 새 언어를 추가하거나 번역을 다듬을 수 있어요.
All user-facing strings live in per-language JSON files. You can add a language or improve a translation by editing JSON only.

## 파일 위치 / Where

```
packages/core/src/i18n/
  index.ts              # LANGUAGES 목록, t() 함수
  locales/
    ko/                 # 기준 언어(한국어) — 모든 키의 원본 / source of truth
      common.json  settings.json  chat.json  …
      index.ts          # 이 언어의 JSON 목록
    en/                 # English
      …
```

이름공간(namespace) 하나가 JSON 파일 하나입니다. 키는 `<파일>.<키>` 로 씁니다. 예: `settings.json`의 `{ "tabs": { "general": "일반" } }` → `t('settings.tabs.general')`.

## 새 언어 추가 / Add a language

1. `locales/en/` 폴더를 통째로 복사해 `locales/<언어코드>/` 로 만듭니다 (예: `ja`, `zh-TW`는 `zhTW`처럼 영문자만).
2. 각 JSON의 **값만** 번역합니다. 키와 `{name}` 같은 자리표시자는 그대로 둡니다.
3. `packages/core/src/i18n/index.ts`에 두 줄을 추가합니다.
   ```ts
   import ja from './locales/ja';
   export const LANGUAGES = [ …, { id: 'ja', name: '日本語', bcp47: 'ja-JP' } ] as const;
   const DICTS = { ko, en, ja };
   ```
4. `pnpm --filter @branch/core test` 로 검사합니다. 빠진 키·남는 키·자리표시자가 다른 문구를 알려 줍니다.

## 규칙 / Rules

- **자리표시자**: `{count}`, `{name}` 등은 번역문에도 똑같이 넣습니다. 순서는 바꿔도 됩니다.
- **복수형(영어 등)**: `count`가 1일 때 쓸 문구는 `<키>_one`으로 추가합니다. 예: `"items": "{count} items"`, `"items_one": "1 item"`.
- **빠진 키**는 한국어로 보입니다. 일부만 번역해도 앱은 동작합니다(검사는 실패하므로 PR 전에 채워 주세요).
- **LLM 프롬프트**(`llm.json`, `skillsBuiltin.json`)는 모델에게 보내는 지시문입니다. 뜻을 바꾸지 말고, 답변 언어를 그 언어로 하라는 문장은 유지해 주세요.
- 마크다운·줄바꿈(`\n`)·이모지는 원문 모양을 따릅니다.

## 개발자용 / For developers

- 코드에서는 `import { t } from '@branch/core'`(UI는 `../i18n`)로 `t('ns.key', { name })`을 씁니다. React 노드를 끼울 때는 UI의 `tx()`를 씁니다.
- 모듈 최상단 상수에서 `t()`를 부르지 말고, 렌더·호출 시점에 부릅니다(데스크톱 main은 언어를 나중에 받습니다).
- 새 문구는 `ko/<ns>.json`과 `en/<ns>.json`에 함께 추가합니다. 새 이름공간은 각 언어 `index.ts`에도 추가합니다.
- 언어 설정은 기기마다 `localStorage['octobooks.locale']`에 저장되며, 바꾸면 앱을 다시 불러옵니다. CLI(bridge·relay·server)는 `OCTOBOOKS_LANG=en`으로 정합니다.
