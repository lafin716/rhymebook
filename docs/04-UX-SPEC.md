# 04 · UX Spec

상태: **확정 (2026-10-09 사용자 컨펌)**. 3단계에서는 이 문서의 UX를 변경하지 않는다.
기준 구현: `packages/ui` (Mock 전용 프로토타입). 화면은 `pnpm dev` 상단 데모 바 또는 `#scenario=<id>`로 바로 연다.

## 1. 반응형 기준

| 구간 | 폭 | 레이아웃 |
|---|---|---|
| mobile | < 768px | 사이드바 = 좌측 드로어, 분할 = 탭, 팝업 = 바텀시트 스택, 마인드맵 = 전체화면(위→아래 배치) |
| tablet | 768–1023px | 사이드바 = 드로어, 분할·팝업·마인드맵은 데스크톱과 동일 |
| desktop | ≥ 1024px | 사이드바 고정(세션 트리), 상단 [마인드맵] 토글, 사이드바에서 끌어 분할(ADR-035) |

- 모바일 우선 설계. 터치 타깃 ≥ 40px, 하단 safe-area 반영.
- 다크/라이트/시스템 테마(설정 › 일반, 상단 바 토글).

## 3. 인터랙션

### 가지 생성
- assistant 메시지 안의 텍스트만 선택 대상. 선택이 메시지 경계를 넘으면 무시.
- 데스크톱: 마우스업 직후 선택 영역 위에 플로팅 메뉴. Esc/바깥 클릭으로 닫힘.
- 모바일: 길게 눌러 선택 → OS 콜아웃과 겹치지 않도록 **하단 액션바**.
- [이게 뭐야?] → `"X"이(가) 뭐야?`, [더 자세히] → `"X"에 대해 더 자세히 설명해줘.`, [직접 질문] → 인라인 입력.
- 생성 즉시 원문에 앵커 하이라이트가 생기고, 서브세션이 **기본 열기 위치**에서 열리며 첫 질문이 자동 전송된다.
- 기본 열기 위치: 모바일 = 바텀시트, 데스크톱 = 설정값(기본 **팝업**, 선택 가능: 분할).

### 앵커
- 원문 markdown offset으로 저장, 렌더 시 텍스트 매칭 + offset 근접 후보로 복원(ADR-002).
- 클릭/탭 → 기본 열기 위치로 서브세션 열기. 요약이 있는 앵커는 이중 밑줄.
- 메시지 하단 "가지 N" 칩 행으로도 열 수 있다.

### 서브세션 헤더
- breadcrumb 각 항목 클릭 → 해당 세션을 메인으로. 깊으면 중간 항목을 `…`로 축약.
- 앵커 인용 블록: 원문 문맥 발췌(앵커 강조) + "원문 위치로"(부모를 메인에 열고 앵커로 스크롤·깜빡임).

### 요약 되돌리기
- [부모에 요약 붙이기] → provider로 1~2문장 요약 초안 생성(스트리밍) → 사용자가 **편집 후** [붙이기] / 취소.
- 부모 앵커 메시지 하단에 접이식 카드("가지 요약 · 제목"), [가지 열기]. 카드 hover 시 원문 앵커 강조.
- 요약이 있으면 버튼은 [요약 다시 만들기].

### 대화 내비게이션 (2단계 피드백 반영)
- 질문 1개 = 턴(질문 + 직후 첫 답변). 턴 목록은 core `buildTurns`가 만든다.
- 채팅 패널 우하단 플로팅 묶음: [목차] · ↑ 이전 질문 · `n/N` 위치 · ↓ 다음 질문. 모든 패널(메인·분할·팝업·시트)에 표시. 모바일 버튼 40px.
- ↑: 현재 질문 머리가 화면 위로 지나갔으면 그 질문 머리로, 아니면 이전 질문으로. ↓: 다음 질문. 이동하면 질문 말풍선이 패널 위쪽에 오고, 포커스가 이동하며 테두리가 잠깐 깜빡인다.
- 메인 패널 단축키: Alt(⌥)+↑/↓. 입력 중인 내용이 있는 입력창에서는 동작하지 않는다.
- 목차: "대화 목차" 패널. 항목마다 Q번호, 질문(2줄), 답변 첫 줄 미리보기(생성 중/없음/에러 표시), 그 답변에서 나온 가지 수. 현재 위치 강조, 누르면 이동. Esc/바깥 클릭으로 닫힘. 모바일은 선택 후 자동으로 닫힘.
- 질문 레일: 데스크톱·태블릿에서 패널 폭이 768px 이상일 때만 오른쪽 가장자리에 질문별 눈금 표시. 현재 질문은 길고 강조된 눈금. 마우스를 올리면 질문 툴팁, 누르면 이동.
- 질문이 1개이고 스크롤할 내용이 없으면 표시하지 않는다.

### 보기 모드
- 상단 바에는 단일/분할 전환이 없고 [마인드맵] 토글만 있다(ADR-035). 분할이 아니면 단일 보기.
- 분할: 사이드바 세션 행을 메인 영역 패널로 끌어 놓는다 — 가장자리(좌·우·상·하) = 그쪽에 새 칸, 가운데 = 그 패널 교체. 놓을 자리는 점선 영역 + "오른쪽에 열기" 등 이름표로 미리 보인다. 최대 4패널(`MAX_SPLIT`), 가득 차면 가운데만. 세션 우클릭 [오른쪽에/아래에 분할로 열기]. 패널 헤더에서 닫기, 하나 남으면 단일 보기. 모바일은 탭(탭별 닫기), 끌기 없음.
- 팝업: 보기 모드와 독립된 오버레이 레이어(ADR-003). 다중, 드래그·리사이즈, 클릭 시 앞으로. 헤더: 분할로 도킹 / 메인에서 열기 / 닫기.
- 마인드맵: 데스크톱 좌→우 / 모바일 위→아래(좁은 노드). 클릭 = 팝업(모바일 시트), Shift+클릭 = 분할에 추가, 더블클릭 = 메인으로. [마인드맵]을 다시 누르면 이전 보기(분할 배치 유지)로.

### 상태
- 스트리밍: 마지막 블록 끝 커서, 중지 시 부분 응답 유지.
- 에러: 부분 응답 + 에러 사유 + [다시 시도].
- 오프라인: 세션 provider가 오프라인이면 입력창 위 배너로 대체 provider 제안(설정의 대체 순서 기준).
- 채팅은 하단 고정 스크롤(사용자가 위로 올리면 해제), 콘텐츠 크기 변화에도 유지.

### 검색·설정
- 검색: Cmd/Ctrl+K(모바일은 상단 검색 아이콘 → 전체화면). 빈 쿼리 = 최근 세션.
- 설정: 데스크톱 모달 / 모바일 전체화면. 웹에서 API 키는 탭 메모리에만 보관한다는 경고를 표시.
  구독 연결은 "내 PC의 공식 CLI" 섹션으로 분리하고, API 키를 공개 배포의 기본 연결로 안내.
- **플랫폼별 연결 (ADR-025, 사용자 요청으로 개편)**
  - PC(데스크톱 앱): 설정 › 연결 = 이 PC의 에이전트(Claude/Codex CLI, 기본 모델·노력치) · API 키(모델 입력) · **원격 페어링 열기**(토글 → 상태 배지·포트·기기 수, 원격 요청 에이전트 선택, [휴대폰·웹 연결 (QR)] → QR·6자리 코드·만료 카운트다운·주소 선택·링크 복사·취소, 이 PC 지문, 페어링된 기기 목록·해제, 고급 relay) · **다른 PC에 연결**(원격 Bridge 페어링) · 데모 · 정책.
  - 웹·모바일: ~~설정 › 연결 = 내 PC 연결 · API 키 · 데모 · 정책~~ → **ADR-026 원격 전용으로 대체** (아래).
- **첫 실행 안내 (ADR-025)**: 쓸 수 있는 연결이 없을 때 한 번 뜨는 모달(모바일 전체화면). [선택] → PC: [이 PC의 CLI (추천)] · [API 키] + "원격 페어링 열기" 안내 / 웹·모바일: [내 PC와 페어링 (추천)] · [API 키]. 선택하면 해당 연결 카드가 그 자리에 나오고 ← 로 돌아간다. 하단 [나중에 하기] · [시작하기](연결 준비 후 활성). 모델 선택 단계는 없다.

### 웹·모바일 원격 전용 (ADR-026, 사용자 요청으로 개편)
- 학습 데이터는 PC에만 있다. 웹·모바일은 페어링한 PC의 세션 목록·대화·진행 중 답변·요약 초안을 실시간으로 보여 주고, 질문·가지·요약·이름 변경·삭제는 PC로 보내 PC의 CLI가 처리한다.
- 미페어링 첫 화면: "PC와 연결하기" 안내(PC 앱에서 설정 → 연결 → [원격 페어링 열기] → [휴대폰·웹 연결]) + 페어링 폼(페어링 링크 / 주소 + 코드, 모바일 앱은 QR 스캔). 웹은 "새로고침하면 다시 페어링" 안내.
- 상단 PC 상태 칩(PC 이름 + 상태 점: 연결됨·연결 중·오프라인), 사이드바 하단 "PC 이름 · 상태". 오프라인이면 배너 + [다시 연결], 입력창·가지 메뉴 비활성.
- 설정(탭 없음): **연결된 PC**(이름·상태·경로 Tailscale/LAN/relay·지문, [다시 연결]·[다른 PC와 페어링]·[연결 해제](확인 대화상자)) · **화면**(테마, 가지 열기 위치) · 이전 로컬 학습이 남아 있으면 [파일로 내보내기] · "원격 학습은 이렇게 동작해요" 안내. API 키·백업·모델·노력치 칩·provider 순서는 없다.
- PC(데스크톱 앱): 원격 기기의 조작은 토스트("<기기 이름>: 질문을 보냈어요" 등)로 알린다. 원격 페어링 카드에서 원격 요청 에이전트(자동 = 준비된 CLI, Claude 우선)와 원격 삭제 허용을 정한다. macOS에서 원격 페어링이 켜져 있으면 창 닫기 = 숨기기(앱이 계속 응답).
- 데모 모드와 개발 서버 `?platform=desktop`(로컬 모드)은 유지.

### 백업 (설정 › 백업)
- 상단 상태 카드: 마지막 백업 시각·위치·크기, [복원] · [지금 백업]. 모바일에서는 두 버튼이 한 줄 전체 폭.
- [복원] → 카드 안에 펼침: 백업 버전 목록(시각, 위치·크기, 암호 잠금 아이콘) 단일 선택 → [합치기 / 전체 교체] → [이 백업으로 복원](교체는 위험 색). "복원 전에 현재 상태를 자동으로 백업" 안내.
- 백업 위치 카드: 파일(이 기기) [JSON 내보내기]/[파일에서 가져오기] · 구글 드라이브 [Google 계정 연결] → 연결됨(계정, 앱 전용 폴더 안내, 연결 해제) · GitHub 저장소(owner/repo + 토큰 입력 → 연결). 자동 백업 대상 카드에 "자동 백업 대상" 배지.
- 자동 백업: [끄기 / 변경 시 / 매일] + 최근 N개(5/10/30) 보관.
- 암호로 백업 잠그기 토글 → 암호 입력 + "잊으면 복원 불가, 암호는 저장 안 함" 경고.
- 하단 안내: 키·토큰은 백업에 포함되지 않으며, 웹에서는 드라이브/GitHub 연결도 탭 메모리에만 보관.

### 추가 기능 (확정 후 추가, ADR-022 — 기존 화면·흐름은 변경 없음)
- **이해 노트**: 상단 바 [이해 노트] 아이콘(루트 세션이 있을 때만) → 모달(모바일 전체화면). 현재 트리의 가지를 계층 번호·깊이 들여쓰기 카드로 나열(제목, 앵커 하이라이트 원문, 요약 또는 "요약 없음" 안내). 카드를 누르면 그 가지를 연다. 하단 [Markdown 저장] · [Anki 카드](요약 있는 가지만, 없으면 비활성) · [복사], 결과는 상태 문구로 안내.
- **서식·메모 (IMP-07, ADR-029)**: 선택 메뉴의 가지 버튼 아래 서식 행 — [형광펜|밑줄|글자색] 모드 + 6색, [굵게]·[기울임]·[명조]·[고정폭], [서식 지우기], [메모]. 서식 버튼은 메뉴를 닫지 않아 연속 적용(누른 상태 aria-pressed 표시). [메모] → 입력칸·[메모 저장]. 모바일은 하단 액션바에 같은 행(2줄), [닫기]로 닫는다. 본문의 메모 텍스트(점선 밑줄+아이콘) 클릭 → 팝오버(보기·수정·삭제).
- **여러 블록 가지 영역 막대 (ADR-030)**: 두 블록 이상에 걸친 가지는 배경 하이라이트 없이 메시지 왼쪽 여백 세로 막대. hover = 범위 강조, 클릭 = 가지 열기.
- **백그라운드 실행 (ADR-028, 데스크톱)**: 원격 페어링이 켜져 있으면 창 닫기 → 트레이에 남음(처음 한 번 알림). 트레이 메뉴 [rhymebook 열기] · 상태 · [완전 종료].
- **앱 내 QR 스캔 (모바일 앱만)**: 설정 › 원격 Bridge › 페어링의 링크 입력 칸 옆 [QR 스캔] → 카메라 → 페어링 링크면 칸을 채운다(아니면 오류 안내). 지문 확인·[연결]은 기존과 같다. 웹·데스크톱에는 표시하지 않는다.
- **입력창 + 메뉴·첨부 (IMP-09, ADR-033)**: 입력창 맨 앞 [+] → [사진 첨부] · [파일 첨부] · 스킬 목록 · [스킬 관리…]. 클립보드 이미지 붙여넣기·파일 끌어 놓기도 첨부. 1,200자/25줄 이상 붙여넣은 텍스트는 본문 대신 "붙여넣은 텍스트" 첨부. 첨부는 입력창 안 위쪽에 한 줄 미리보기(사진 썸네일, PDF·파일 이름·크기 칩, 붙여넣은 텍스트 첫 줄·글자 수, 각 [×]). 누르면 크게 보기(사진)·전체 텍스트. 보낸 질문 위에도 같은 미리보기(읽기 전용). 첨부만 보내도 된다.
- **스킬 (IMP-09, ADR-034)**: 입력창에서 `/` → 스킬 후보(↑↓·Enter·Tab, Esc 닫기) → 입력창 위 스킬 칩(✦ 제목 `/명령` [×]). `/명령 나머지`로 바로 보내도 적용. 보낸 질문 위에 스킬 배지. 스킬 관리 페이지(사이드바 하단 [스킬 관리], + 메뉴): 전체 화면, 데스크톱 = 목록 + 편집 두 칸, 모바일 = 목록 → 편집(저장 후 목록). 필드: 명령 이름(`/`), 제목, 설명, 지시(글자 수). [새 스킬]·[저장]·[되돌리기]·[삭제](확인), 저장하지 않고 나가면 확인. 기본 예시 **커리큘럼 생성**(`/curriculum`).

## 4. 데모 바
- 개발 서버(`import.meta.env.DEV`)에서만 상단에 표시, 접기 가능. 각 시나리오는 시드 데이터로 초기화 후 실행.
- 프로덕션 빌드에서는 렌더되지 않는다(3단계에서 MockProvider는 "데모 모드"로만 유지).
