# 00 · Vision — Branch Learn (가칭)

> **질문이 생긴 자리에서 가지를 친다.**

## 문제 정의

LLM 채팅으로 무언가를 배울 때 학습자는 답변을 읽다가 모르는 단어·문장을 자주 만난다.
지금의 채팅 앱에서는 선택지가 두 가지뿐이다.

1. **같은 대화에서 되묻기** — 본 흐름이 곁가지 질문으로 오염되고, 원래 읽던 위치로 돌아가기 어렵다.
   대화가 길어질수록 모델의 맥락도 흐려진다.
2. **새 채팅을 열기** — 맥락이 끊긴다. "아까 그 설명에서 말한 Q가 뭐냐"를 다시 설명해야 한다.

결국 학습자는 질문을 참거나(이해 공백이 쌓임), 흐름을 잃는다(학습 피로).
"모르는 것을 모르는 채로 넘어가는 비용"이 학습 채팅의 핵심 마찰이다.

## 해결 방식

- 답변 속 **모르는 부분을 드래그**하면 그 자리에서 **서브세션(가지)** 이 열린다.
- 서브세션은 **부모의 맥락을 상속**하므로 "이 맥락에서 이 단어가 뭐냐"를 짧게 물을 수 있다.
- 가지는 **깊이 제한 없이** 다시 가지를 칠 수 있다(모르는 것의 모르는 것).
- 이해가 끝나면 **1~2문장 요약을 부모 메시지에 카드로 되돌려** 본 흐름에 흡수한다.
- 전체 탐구 경로는 **마인드맵(세션 트리)** 으로 한눈에 보이고, **분할/팝업**으로 나란히 읽을 수 있다.

## 핵심 가치

| 가치 | 의미 |
|---|---|
| 흐름 보존 | 본 대화는 깨끗하게 유지되고, 곁가지는 원문 위치(앵커)에 매달린다 |
| 맥락 상속 | 가지는 조상 앵커 체인과 부모 대화를 알고 시작한다 |
| 이해의 회수 | 가지에서 얻은 이해가 요약 카드로 부모에 돌아온다 |
| 구조의 가시화 | 무엇을 몰랐고 어떻게 풀었는지가 트리로 남는다 |
| 내 구독/키 그대로 | 공식 CLI(Claude/Codex) 또는 API 키를 사용자가 직접 연결한다 |

## 타깃 사용자

- **주 타깃**: 새 기술·학문 분야를 LLM과 함께 독학하는 개발자·대학(원)생·연구자
  (예: 트랜스포머 논문을 읽으며 개념을 하나씩 파고드는 사람)
- **부 타깃**: 업무상 낯선 도메인(법률, 금융, 의료 용어 등)을 빠르게 파악해야 하는 실무자
- **환경**: 데스크톱에서 깊게 공부하고, 이동 중 모바일로 이어서 복습/질문한다.
  이미 Claude/ChatGPT 구독 또는 API 키를 보유한 사용자가 많다.

## 성공 지표 (MVP 가설)

- 한 학습 세션당 생성되는 가지 수 ≥ 3 (질문을 참지 않고 친다)
- 가지 중 요약 되돌리기 비율 ≥ 40% (이해를 회수한다)
- 가지 생성 → 첫 응답 토큰까지 3초 이내 (흐름이 끊기지 않는다)

## 하지 않는 것 (철학적 경계)

- 학습 관리 시스템(LMS)이 아니다: 퀴즈·플래시카드·간격 반복은 MVP 범위 밖.
- 계정/클라우드 동기화를 만들지 않는다: 데이터는 기기 로컬에 둔다.
- 비공식 경로로 구독을 우회하지 않는다: OAuth 토큰 추출·헤더 위조 금지 (03-PROVIDERS.md 정책).
