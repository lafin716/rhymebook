# octobooks visual identity

Concept: **호기심이 뻗는 만큼, 나의 배움도 깊어져요.** Octopus arms connect small questions into a personal branching learning map. Display wordmark lowercase octobooks, small PREVIEW label. Original vector mark combines a rounded octopus head, eight branching arms/nodes and open-book gesture. Use the same mark in app chrome, empty states, onboarding and all platform icons.

Ocean default uses ink #173c4b, teal #087e8b and mist #eef7f8; Lagoon adds mint, Coral warm reef pink, Abyss indigo, Pearl neutral sand. Every palette supports light and dark independently. Keep semantic token usage consistent in chat, settings, popup, sheets, mindmap, vault and controls. Add sidebar identity/section hierarchy and quiet background details to onboarding/empty views; reading surfaces stay uncluttered. 14–16px body, Korean system font stack, clear keyboard focus, 40px icon targets, 44px primary touch targets. Palette cards have names, summaries, swatches and selected check/aria state. Never convey selection by color alone.

Screenshots: desktop 1440×900, mobile 390×844, tablet 820×1180; light/dark and all palette swatches, long session labels, settings scroll, sidebar tree, split and mindmap. No stock imagery or raster AI required: established source-vector icon pipeline is retained; PNGs are generated from original SVG via repository script.
