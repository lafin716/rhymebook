# 예약과 로컬 알림

대화에서 `/schedule`을 선택하거나 “매일 오전 9시에 영어 퀴즈 내줘”, “30분 후에 오늘 배운 내용을 복습하도록 알려줘”라고 요청하면 예약 스킬을 자동으로 사용합니다. 날짜·시간·작업이 모호하면 먼저 되묻습니다. 검증된 예약은 대화의 예약 카드와 사이드바 **예약 관리**에서 확인할 수 있습니다.

## 예약 관리

- 새 예약: 이름, 실행할 질문, 대상 대화, 다음 실행 시간과 반복 주기를 선택합니다.
- 반복: 한 번, 매일, 평일, 매주, 매월. 매주는 첫 실행 날짜의 요일을 따릅니다. 매월 31일처럼 없는 날짜는 그 달 마지막 날에 실행하고 다음 달에는 원래 날짜를 사용합니다.
- 수정, 일시정지/재개, 삭제, 대상 대화 열기를 지원합니다. 실행 중에는 변경할 수 없습니다.
- 예약 시간에 같은 대화로 질문을 보내며 해당 세션의 AI 연결·모델 설정을 사용합니다. 완료 응답은 그 대화에 남습니다. 오류는 예약 목록에서 확인하며, 중단된 응답은 대화에서 다시 시도할 수 있습니다.
- 완료된 일회성 예약을 다시 실행하려면 미래 시간으로 수정해 저장하세요.

예약은 기기에만 저장되며 원격 PC 프로필이나 별도 세션 창에서는 관리할 수 없습니다. 연결한 PC의 메인 창에서 관리하세요. 웹·모바일의 **이 기기** 프로필에서도 로컬 예약을 관리할 수 있습니다.

앱이 실행 중일 때만 동작합니다. 데스크톱 앱을 트레이로 숨겨도 계속 실행하지만, 앱 종료·절전 중에는 실행하지 않습니다. 지난 회차들은 다음 시작 시 한 번으로 묶어서 처리합니다. OS가 웹·모바일을 중지한 경우에도 다음 활성화 시 처리합니다. 시간은 등록 시 기기 시간대를 기준으로 해석하며 반복 계산은 실행 기기의 현재 달력을 사용합니다. 여행 등으로 시간대를 변경했다면 다음 실행 시간을 확인하세요.

## 응답 완료 알림

**설정 → 일반 → 응답 완료 알림**에서 조정합니다. 기본값은 켬이며 이 기기에만 적용됩니다.

- 데스크톱은 OS 로컬 알림을 사용합니다. 알림을 누르면 앱과 해당 대화가 열립니다.
- 웹은 알림을 지원하는 브라우저에서 **권한 허용**을 눌러 사용합니다. 권한 창을 자동으로 띄우지 않습니다.
- **테스트 알림**으로 확인할 수 있습니다. OS 알림 설정이나 방해금지 모드가 배너 표시를 막을 수 있습니다.
- 실패·취소된 생성이나 예전 응답을 다시 불러올 때는 완료 알림을 보내지 않습니다. 원격 프로필은 연결 중 실제로 관찰한 완료 응답만 알립니다.
- 모바일 앱은 Android·iOS 네이티브 로컬 알림을 사용합니다. **권한 허용**을 누르면 OS 권한을 요청하며, 거부한 경우 기기 설정에서 OctoBooks 알림을 허용하세요. 앱으로 돌아오면 권한 상태를 다시 확인합니다.
- 모바일 알림을 누르면 해당 대화가 열립니다. 아직 PC의 대화를 읽는 중이면 최대 30초 기다립니다. 다른 PC·프로필의 알림이거나 대화를 찾지 못하면 안내를 표시합니다.
- 앱이 종료되거나 OS가 실행을 중지한 동안 새 응답을 수신하는 서버 푸시 기능은 포함하지 않습니다. 이미 생성된 로컬 알림은 OS 알림 센터에서 확인할 수 있습니다.
