# 비밀번호 저장: 해시와 솔트

비밀번호는 평문으로 저장하지 않는다. 유출되었을 때 원래 값을 되돌릴 수 없도록 느린 해시 함수로 바꿔 저장한다.

## 권장 알고리즘
- Argon2id: 메모리 사용량을 함께 요구해 GPU 공격을 어렵게 한다. 신규 시스템의 1순위다.
- bcrypt: 오래 쓰였고 널리 지원된다. 비밀번호 길이 72바이트 제한에 주의한다.
- SHA-256 한 번 해시는 너무 빨라서 쓰지 않는다.

## 솔트
사용자마다 무작위 솔트를 붙여 같은 비밀번호라도 해시가 달라지게 한다. 라이브러리가 솔트를 해시 문자열 안에 함께 넣어 준다.

## 로그인 검사
저장된 해시와 입력값을 상수 시간 비교로 확인한다. 실패 메시지는 아이디가 있는지 없는지 드러내지 않게 같은 문구로 낸다.
