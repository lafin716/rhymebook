# inode 고갈 문제

파일 시스템은 파일마다 inode라는 메타데이터 구조체를 하나씩 쓴다. 디스크 용량이 남아 있어도 inode가 모두 쓰이면
새 파일을 만들 수 없고 `No space left on device` 오류가 난다.

## 확인
- `df -i`로 inode 사용률을 본다. `df -h`는 용량만 보여준다.
- 작은 파일이 수백만 개 쌓인 디렉터리(세션 캐시, 메일 큐, 로그 조각)가 주범인 경우가 많다.

## 해결
오래된 임시 파일을 지우거나, 파일을 묶어서 줄인다. 근본적으로는 inode 수를 미리 넉넉히 잡도록 `mkfs.ext4 -i` 값을 조정해야 한다.
이미 만든 파일 시스템의 inode 수는 바꿀 수 없다.
