# 코사인 유사도와 벡터 정규화

임베딩 벡터끼리 얼마나 같은 방향을 가리키는지 재는 값이 코사인 유사도다. 1에 가까울수록 의미가 가깝고, 길이는 무시한다.

## 계산
두 벡터의 내적을 각 길이의 곱으로 나눈다. 벡터를 미리 길이 1로 정규화해 두면 내적만 구하면 된다. 검색 시 매번 나눗셈을 줄일 수 있다.

## 주의
- 정규화하지 않은 벡터를 내적으로만 비교하면 긴 문서가 이긴다.
- 모델마다 점수 분포가 다르므로 임계값을 한 모델에서 정한 값을 다른 모델에 그대로 쓰면 안 된다.
- 해시 기반 로컬 임베딩은 단어가 겹칠 때만 점수가 올라가서 의미 검색 효과가 제한적이다.
